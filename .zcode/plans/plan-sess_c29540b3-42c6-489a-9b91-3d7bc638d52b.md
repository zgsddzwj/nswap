## 1. 已确认决策

主体：自己的个体工商户 + 居委会/物业/楼长运营背书（账号归自己、可跨社区扩张、未来可商业化；邀请码经组织渠道发放借用公信力）｜结算：MVP 线下当面交易不碰资金，预留 payment 扩展｜形态：出售/赠送/换物/求购四形态全做｜后端：Python FastAPI + 微信云托管（容器）｜前端：原生小程序 + TypeScript + TDesign｜范围：单社区 MVP，全表 community_id 贯通预留多社区。

## 2. 产品定位与竞品借鉴（调研全文落 docs/01）

**定位**：以小区为单位的"邻里闲置交换站"，替代微信群刷屏卖闲置。
**三原则**：①准入验证是地基（Nextdoor 活/鱼塘死）②状态机消灭"还在吗"（反58教训）③赠/求/谢最轻流程是氛围引擎（Buy Nothing）。

**取其精华**：闲鱼极简发布流+出价代替砍价｜Buy Nothing 赠/求/感谢三帖+门口自提+自由挑选意向（不先到先得）｜Nextdoor 住址验证（改造为邀请码+老住户担保，徽章到栋不到户）｜OfferUp 楼栋过滤｜多抓鱼成色分级话术库｜双向确认履约（闲鱼换物被骗教训）。
**去其糟粕**：付费置顶推广、职业贩子（同时在架≤20件/日发≤5件频控）、验机重资产、快递担保交易、重内容社区（鱼塘被监管关停教训）、估价黑箱。

## 3. 功能架构：7 大模块

```
小程序端（住户视角）                          管理后台（Web /admin）
├─ M1 身份与准入：登录/验证/资料/角色          └─ M7 管理端：看板/邀请码/巡查/
├─ M2 发布管理：四形态发布/图片/管理              举报处置/用户管理/安全记录
├─ M3 浏览发现：feed/筛选/搜索/详情/收藏/留言
├─ M4 交易闭环：意向/挑选/约定/双向确认/互评/感谢
├─ M5 消息通知：通知中心/轻会话/订阅消息
└─ M6 我的与信用：信用档案/我的发布/收藏/交易/举报/协议
```

### M1 身份与准入
- **功能**：微信静默登录（callContainer 注入 openid）；邀请码验证（主通道：邀请码由居委会/物业/楼长组织渠道按楼栋发放，绑定楼栋后成为已验证住户）；老住户担保（已验证且≥1笔完成交易的住户可担保1名新邻居）；人工审核（业主凭证图片上传→后台通过）；资料编辑（昵称/头像/楼栋单元）；角色（超管/楼长/住户）
- **入口与跳转**：启动静默登录；未验证时 home 顶部横幅、mine 卡片 → `verify` 页 → 验证成功回 home 解锁发布/意向

### M2 发布管理
- **功能**：四形态差异化表单（出售：图+标题+分类+成色+价格+可小刀+描述；赠送：图+标题+描述，免定价免成色最轻；换物：+「想换什么」；求购：标题+「想要什么」+可出价）；图片 1-9 张（压缩直传云存储→mediaCheckAsync 异步检测）；编辑/手动下架/删除；免费续期（72h 冷却防刷屏）；自动规则（14天无互动沉底+通知一键续期/下架，30天未处理归档）
- **入口与跳转**：Tab2 四宫格（卖/送/换/求）→ `publish/edit`（type 参数）→ 成功 → `detail`

### M3 浏览发现
- **功能**：「今日新出」feed（顶部横滑最近感谢帖）；形态×分类×楼栋三维筛选；关键词搜索（标题+描述）；详情页（图轮播/成色/楼栋/状态角标/卖家信用入口/收藏/公开留言板——先检后显）；状态角标：在售/已预约/已完成/已沉底
- **入口与跳转**：home 卡片 → `detail`；搜索框 → `search` → `detail`；detail 卖家头像 → `profile`

### M4 交易闭环（核心）
- **功能**：「我想要」意向（求购帖按钮变「我可以提供」，同一意向模型对称复用；换物可附「我用Y换」；可小刀物品可附出价）→ 卖家意向列表自由挑选接受（不排队）→ 意向被接受后开放轻会话，商定时间+交接方式（当面/放门口自取/物业前台）→ 状态置「已预约」停止收新意向 → **双方各自确认完成才关单**（换物双向履约）→ 互评（1-3星+留言）→ 可发感谢帖；取消/爽约记入信用事件
- **入口与跳转**：detail 底部主按钮（我想要/和TA聊聊/编辑，按角色与状态切换）→ want-sheet；卖家在 detail/wants 管理意向；chat 内「去约定」→ `trade`；messages 通知直达对应页；trade 完成 → `review` → my-trades

### M5 消息通知
- **功能**：通知中心（新意向/被选中/预约/待确认/新评价/系统）；会话列表+轻会话（纯文本，轮询）；微信一次性订阅消息（4 模板：新意向-卖家/意向被接受-买家/待确认提醒-双方/新评价，关键动作前 requestSubscribeMessage）
- **入口**：Tab3；detail「和TA聊聊」（仅意向被接受后开放，防骚扰）→ `chat`

### M6 我的与信用
- **功能**：信用档案（卖/送/换成交数、好评率、被感谢数、违约记录——只展示客观数据不做黑箱评分）；我的发布（按状态 tab）；收藏；我的交易（进行中/已完成）；举报（商品/留言/用户）；用户协议+隐私指引；管理员可见「管理后台」入口（复制链接浏览器打开）
- **入口**：Tab4 及其二级页

### M7 管理后台（FastAPI + Jinja2 + Bootstrap，免前端构建链）
登录（独立账号密码+session）｜数据看板（用户/发布/交易/举报趋势）｜邀请码管理（按楼栋批量生成/导出/作废，供居委会/物业/楼长分发）｜内容巡查（全量商品+下架）｜举报处置（待处理→下架/驳回）｜用户管理（封禁/人工验证审核/担保审核）｜内容安全记录（mediaCheck 回调）

## 5. 后端 API 设计（11 个业务 router + 回调 + admin）

- `auth`：POST /api/auth/login、GET/PUT /api/me
- `community`：POST /api/community/join（邀请码）、POST /api/community/vouch、GET /api/community/info
- `items`：GET /api/items（feed+三维筛选+搜索+分页游标）、POST /api/items、GET/PUT/DELETE /api/items/{id}、POST /api/items/{id}/renew、POST /api/items/{id}/off-shelf
- `wants`：POST/GET /api/items/{id}/wants、PUT /api/wants/{id}（接受/拒绝）
- `messages`：GET/POST /api/items/{id}/messages（留言板）
- `chat`：GET/POST /api/conversations、GET/POST /api/conversations/{id}/messages（轮询，since 游标）
- `trades`：POST /api/trades（意向→交易/预约）、PUT /api/trades/{id}/confirm、PUT /api/trades/{id}/cancel、POST /api/trades/{id}/review、POST /api/trades/{id}/gratitude
- `favorites`：POST/DELETE /api/items/{id}/favorite、GET /api/favorites
- `reports`：POST /api/reports
- `notifications`：GET /api/notifications、POST /api/notifications/subscribe（记录授权）
- `uploads`：POST /api/uploads（图片登记+发起异步检测）
- `wechat_callback`：GET/POST /api/wechat/callback（消息推送验证 + mediaCheck 回调：违规自动隐藏）
- `admin`：/admin/* 页面 + 动作路由（M7 全部功能）
- services：wechat.py（code2session/msgSecCheck/mediaCheckAsync/订阅消息，云托管开放接口服务优先，DEV_MODE 可 mock）、sec_check.py（先检后发编排+降级隐藏待人工）、credit.py、expiry.py（APScheduler 每日沉底/归档扫描）、notify.py

## 8. 技术架构要点

原生小程序(TS+TDesign) —wx.cloud.callContainer(自动注入 X-WX-OPENID 免 token)—> 云托管容器 FastAPI(uvicorn)；图片 wx.cloud.uploadFile 直传云存储+CDN；MySQL（云托管数据库，SQLAlchemy 2.0+Alembic）；开放接口服务免 access_token 调 code2session/msgSecCheck/mediaCheckAsync/订阅消息；mediaCheck 回调由云托管默认公网域名承接；本地开发 docker-compose + DEV_MODE 假 openid（无需真实 AppID 即可联调）；云托管按量+最小规格 MySQL，低流量月成本几十元内（以控制台为准）。

## 9. 合规与上线 checklist（全文落 docs/05）

①**注册个体工商户**（0 元、无注册资本；省政务 APP 全程网办 1-3 工作日；经营场所三方案：住宅登记（部分城市需居委会同意证明，可与背书合作一并办）/网络经营场所（电商专用）/集群注册；经营范围建议：技术服务、技术开发、软件开发、日用百货销售、**旧货销售**；后续义务：每季度零申报（免费，不申报会罚款））→ ②以个体户注册小程序账号（免费；微信认证 300 元/年可选，接支付时再办）→ ③小程序 ICP 备案（免费、强制、1-20 工作日，开发期并行办）→ ④开通云托管环境 → ⑤配置开放接口服务+消息推送回调+4 个订阅消息模板 → ⑥类目策略：以「社区生活服务/闲置交换信息工具」定位提审，页面文案避开「购买/订单/支付」（用「交换/赠送/约定」），备用类目「环保回收」→ ⑦用户隐私保护指引（不采集精确 GPS、不强制手机号）→ ⑧用户协议（平台不介入资金、纠纷社区调解、当面验货事后不退）→ ⑨体验版小区内测约 50 人 → ⑩提审发布 → ⑪上线运营：请居委会/物业/楼长转发邀请码完成首批准入（合作方案见 docs/06）。
**全景成本**：个体户注册+申报 0 元、刻章 0~200 元可选、认证 300 元/年可选、云资源月几十元、备案/小程序注册 0 元——首年约 400~800 元。
风险：个体户 C2C 信息撮合类目口径不确定，提审前微信开放社区发帖确认，被拒则按备用类目收缩。
