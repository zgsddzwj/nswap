# 11 · 发布体验优化与图片安全详设

> 状态：**已实施**（main）｜前置：docs/07/08/09
> 背景：对齐闲鱼/转转的发布体验（用户提出），并解决图片两个问题：实况图支持、默认"打码"。

## 1. 调研结论

| 议题 | 调研结论 |
|---|---|
| 分类 | 闲鱼**有**分类但为"智能推荐"（不打断输入流）；转转强制先选类目（重品类业务）。差异感受来自"选不选"而非"有没有" |
| 实况图（Live Photo） | 微信官方 API 限制：`wx.chooseMedia` 选实况图**只返回静帧，动效视频被剥离**，小程序拿不到——真 Live 效果在小程序内不可实现 |
| 图片水印 | 闲鱼/转转上传图片均自动加平台水印：防盗图、脱离平台的截图可溯源 |

## 2. 方案与实施

### 2.1 分类免选（对齐闲鱼）
- 发布表单**去掉分类步骤**（图片+标题+描述+价格一气呵成）
- 后端 `services/categorize.py`：标题/描述关键词 → 类目自动识别（**长度加权**打分，长词优先解决"书/书架"类冲突）；未命中归 other
- `ItemPayload.category` 改可选；创建/编辑均自动识别；浏览端筛选条不变（数据质量由自动分类保证）
- 词表即配置（`categorize.py`），按运营数据持续补词

### 2.2 图片处理管线（比水印更重要的隐私发现）
**核实发现：上传管线原本原图直传——iPhone 照片 EXIF 含 GPS 坐标与设备信息，查看原图/下载即可读出住户位置，与"不采集定位"承诺冲突（P0 级隐私问题）。**

新增 `services/imaging.py`，上传双入口（multipart/base64）统一经过：
1. **EXIF 全清除**（先按方向摆正再丢弃，防躺倒图；GPS/设备信息不落盘）
2. **右下角半透明 "nswap" 水印**（细描边，明暗底可见；防盗图+溯源）
3. **HEIC 兼容**：iPhone 原图（.heic/.heif）自动转 JPEG
4. 严格模式：无法解析的图片直接 400，不做宽松降级（保证 EXIF 清除不失效）

依赖：Pillow + pillow-heif + piexif（测试构造 GPS 用）。

### 2.3 实况图
- 现状已天然兼容：住户选实况图 → 自动取静帧展示存储，零开发
- 发布页加提示「实况照片将取静帧展示」；"真 Live 效果"列为 P2 探索（依赖 iOS API 变动，不建议投入）
