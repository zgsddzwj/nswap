# nswap 上线 Checklist

> 按①→⑪顺序执行；③备案与开发并行，不要等代码写完才办。

## ① 注册个体工商户（0 元，1-3 个工作日）

- **渠道**：所在省政务服务 APP / 政务服务网「个体工商户设立登记」全程网办；或政务大厅市场监管窗口
- **费用**：登记免费、无注册资本；刻章可选 0~200 元（不少城市政府免费送）；代账/代办都不需要
- **材料**：身份证 + 经营场所证明
- **经营场所三方案**（按当地政策选）：
  1. 住宅登记：多数城市允许，部分需居委会/业委会「住改商」同意证明——**与跑居委会背书邀请码是同一拨人，一趟办两件事**
  2. 网络经营场所登记：电商法允许纯线上经营者用网络经营地址，无需实体（各地执行有差异）
  3. 集群注册：部分创业园区提供虚拟地址
- **经营范围建议**：技术服务、技术开发、技术咨询、软件开发、日用百货销售、**旧货销售**（国民经济行业分类标准条目，提审类目可能用上）
- **⚠ 后续义务**：每季度记账报税（无收入就零申报，电子税务局自己点几下，免费；**不申报会罚款**）；哪天不做了走简易注销

## ② 注册小程序账号（免费）

- mp.weixin.qq.com → 立即注册 → 小程序，主体选**个体工商户**（填营业执照信息）
- 获取 **AppID**；管理员微信绑定自己的
- 微信认证 300 元/年：**MVP 阶段可不认证**（无支付不需要），接入支付时再办
- 拿到 AppID 后填入 `miniprogram/project.config.json` 的 `appid`

## ③ 小程序 ICP 备案（免费，强制，1-20 个工作日，开发期并行办）

- 小程序后台 → 设置 → 基本设置 → 小程序备案，按指引填主体信息（个体户）
- 流程：填信息 → 平台初审（1-2 工作日）→ 工信部 12381 短信核验（24h 内完成）→ 通管局审核
- **备案期间用「体验版」内测，不受影响**

## ④ 开通微信云托管

- 访问微信云开发/云托管控制台（cloud.weixin.qq.com），关联小程序 AppID
- 开通**云托管**服务与 **MySQL 数据库**（最小规格起步）
- 记录：环境 ID、服务公网默认域名（形如 `https://xxx.sh.run.tcloudbase.com`）
- **图片存储**：MVP 代码用容器本地盘（重新部署会丢图片！），正式运营前在 `backend/app/api/uploads.py` 的 `save_upload()` 切换为云托管对象存储/COS（单函数替换点，注释已标注）
- 计费参考：按量（CPU/内存/流量）+ MySQL 实例，低流量月成本几十元内，以控制台实时价格为准

## ⑤ 部署后端 + 微信侧配置

- 云托管「代码上传/Git 部署」上传 `backend/`；环境变量按 `docs/03` 第 5 节：
  `ENV=prod`、`DATABASE_URL=<云托管MySQL>`、`PUBLIC_BASE_URL=<云托管公网域名>`、
  `WX_CALL_MODE=cloud`、`ADMIN_SESSION_SECRET=<随机串>`、`ENABLE_SCHEDULER=true`
- 首次部署后：执行 `alembic upgrade head`；运行 `scripts/seed.py` 建 Community + admin（**立即在 /admin 改默认密码**）
- **开放接口服务**：云托管控制台开启「微信调用/开放接口」，使容器内可免 access_token 调 code2session / msgSecCheck / mediaCheckAsync
- **消息推送**：mp 后台 → 开发 → 开发设置 → 消息推送：
  URL = `https://<云托管域名>/api/wechat/callback`，明文模式，记录 token 也可不启用 token 校验（MVP）
- **订阅消息**：mp 后台 → 功能 → 订阅消息，申请 4 个「一次性模板」：
  新意向提醒（卖家收）/ 意向被接受（买家收）/ 交易待确认 / 收到新评价
  模板 ID 填入后端环境变量 `MSG_TPL_*`
- **uploadFile 合法域名**：mp 后台 → 开发设置，把云托管公网域名加入 request/uploadFile 合法域名

## ⑥ 类目与审核策略（最关键的不确定点）

- **定位话术**：「社区邻里闲置物品公益交换信息工具」，弱化电商属性
- **页面文案红线**：全局不出现「购买/下单/订单/支付/购物车」——统一用「交换/赠送/约定/意向」；价格展示为「参考价」
- **提审类目首选**：生活服务相关（如「生活服务-综合生活信息」类，以个体户可选类目清单为准）；**备用**：「商业服务-环保回收/废品回收」（有开源项目以该类目上架二手信息服务的先例）
- **提审前**：微信开放社区（developers.weixin.qq.com/community）发帖询问「个体户主体、闲置物品信息撮合（无支付、线下当面交易）应选何类目」，留存答复截图
- 若被驳回：按驳回意见收缩（去掉求购/价格字段，纯「赠送+交换」公益定位）用备用类目重提

## ⑦ 用户隐私保护指引（mp 后台 → 设置 → 服务内容声明）

- 声明收集：微信昵称头像（用户主动填写）、相册/相机（发布图片用）、 openid
- **产品策略已对齐**：不采集精确 GPS（楼栋为手填文本）、不强制手机号
- 配置隐私接口（如选用头像昵称填写能力需声明）

## ⑧ 用户协议 / 隐私政策（`miniprogram/pages/agreement` 富文本）

必备条款：
1. 平台仅提供信息发布与流程记录，**不介入资金往来**，交易双方线下当面自行结算
2. **当面验货、钱货两清后交易即完结，事后不支持退换**；纠纷先自行协商，可请楼长/物业/居委会调解
3. 用户对其发布内容合法性负责；禁止发布违禁品（药品/医疗器械、烟花爆竹、动物活体、色情、赌博、假冒、盗版、个人信息等）
4. 违规处置：下架/封禁/移交有关部门
5. 换物/赠送建议当面完成双方确认；平台记录爽约/违约行为并在信用档案展示

## ⑨ 体验版内测（~50 人，备案完成前后皆可）

- 上传代码 → 设为体验版 → 添加体验成员（或用体验二维码）
- 后台生成邀请码 → 请居委会/物业/楼长在业主群发放（首批种子用户）
- 观察指标：验证率、人均发布、意向转化、当面交接完成率
- 修复问题后再次上传

## ⑩ 提审发布

- 提审前自检清单：
  - [ ] 全局文案无电商字眼（搜「买/订单/支付」）
  - [ ] 未登录/未验证/无网络/空列表 四种状态可正常浏览
  - [ ] 举报入口可用且后台能处置
  - [ ] 内容安全已在生产模式生效（WX_CALL_MODE=cloud）
  - [ ] 用户协议/隐私指引页可访问
  - [ ] 类目材料已备好
- 提审 → 通过 → 全量发布

## ⑪ 上线运营启动（详见 06-运营手册）

生成首批邀请码 → 居委会/物业群转发 → 招募 3~5 名楼长 → 选启动时机（毕业季/搬家季/年末大扫除）。
